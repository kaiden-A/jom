Most websites are made from a surprisingly small set of tags. Headings, paragraphs, links, images, and lists. That's the bulk of it. Once you're comfortable with these, the rest of HTML is mostly details.

## The tags you'll use every day

### Headings

There are six levels, `<h1>` through `<h6>`. They describe importance, not size:

```html
<h1>The page title</h1>
<h2>A section</h2>
<h3>A smaller section</h3>
```

Use **one `<h1>` per page**. It's the main title. Then use `<h2>` for sections and `<h3>` for subsections. Don't pick a heading because it "looks the right size" — that's CSS's job. Pick it because it describes the structure.

### Paragraphs and emphasis

```html
<p>This is a paragraph. It holds a block of text.</p>
<p>You can make text <strong>important</strong> or <em>emphasized</em>.</p>
```

`<strong>` means "this matters" and usually renders bold. `<em>` means "stress this word" and usually renders italic. They're not just styling shortcuts — they tell the browser (and screen readers) what the text means.

### Links

```html
<a href="https://example.com">Visit example.com</a>
<a href="/about">About this site</a>
```

The `href` is where the link goes. It can be:

- **Absolute** — a full URL, like `https://example.com`.
- **Relative** — a path inside your site, like `/about` or `contact.html`.
- **An anchor** — a jump to a section on the same page, like `#food-log`.

If the link opens in a new tab, add `target="_blank"` **and** `rel="noopener"`. The `rel` part is a small security habit worth keeping.

### Images

```html
<img src="food.jpg" alt="A bowl of chicken and rice" width="480" height="320">
```

- `src` is the file path or URL.
- `alt` is the text alternative. It's what screen readers say, and what shows if the image fails to load. **Never skip it.** If the image is purely decorative, use `alt=""`.
- `width` and `height` help the browser reserve space while the image loads, so the page doesn't jump around.

### Lists

```html
<ul>
  <li>Chicken breast</li>
  <li>Rice</li>
  <li>Broccoli</li>
</ul>

<ol>
  <li>Enter your details</li>
  <li>Pick a goal</li>
  <li>Add your food</li>
</ol>
```

`<ul>` is an unordered list (bullets). `<ol>` is ordered (numbers). Each item is an `<li>`. Lists can nest — just put the nested list inside the `<li>` it belongs to.

## The mistakes everyone makes

- **Forgetting the closing tag.** `<p>Hello` works until it doesn't. Close your tags.
- **Using `<br>` to create space.** Use paragraphs, lists, and later CSS margins. `<br>` is for a line break inside a sentence, like an address.
- **Using `<div>` for everything.** We'll cover semantic tags next lesson. They make your page easier to read and better for accessibility.
- **Empty alt text on meaningful images.** If the image carries information, describe it.
- **Headings picked by size.** Pick by hierarchy; style with CSS.
