The page is built. The CSS looks good. Now we need to connect the form to the math.

That connection is an **event**: the browser tells you something happened, and you run a function in response.

## addEventListener

```js
const button = document.querySelector("#calculate");

button.addEventListener("click", () => {
  console.log("Clicked!");
});
```

`addEventListener(eventName, handler)` registers a function to run when the event happens on that element.

Common events:

- `click` — a button, link, or anything clickable.
- `submit` — a form is submitted (button click or Enter).
- `input` — the value changes as the user types.
- `change` — the value changes and the field loses focus (good for selects).
- `keydown` — a key is pressed.

<Callout variant="tip" title="Use submit, not click, for forms">
If you listen for `click` on the submit button, pressing Enter in a field won't trigger your code. Listen for `submit` on the `<form>` instead. It handles both.
</Callout>

## The event object and preventDefault

```js
form.addEventListener("submit", (event) => {
  event.preventDefault();
  // handle the form ourselves
});
```

By default, submitting a form sends a request and reloads the page. We don't want that — we want to calculate in the browser. `event.preventDefault()` stops the default behavior.

## Reading form values

```js
const age = Number(document.querySelector("#age").value);
const activity = document.querySelector("#activity").value;
const sex = document.querySelector('input[name="sex"]:checked').value;
```

- `.value` is a string, always. `"25"`, not `25`.
- `Number(...)` converts it. `Number("")` is `0`, so check for empty fields too.
- For a radio group, select the checked one with `input[name="sex"]:checked`.
- For a select, `.value` is the selected option's `value`.

<Callout variant="warn" title="The string trap">
```js
const height = "170";
const weight = "70";
console.log(height + weight); // "17070"
```
If you forget to convert, JavaScript glues strings together. Convert with `Number()` before doing math. If the result is `NaN`, one of the values wasn't a number.
</Callout>

## Updating the result

```js
const result = document.querySelector("#result");
result.textContent = "Your target is " + Math.round(target) + " kcal";
```

That's it. Select the element once, update its text when the calculation is done.

## The mistakes everyone makes

- **Forgetting `event.preventDefault()`.** The page reloads and your result disappears.
- **Listening for `click` on the button instead of `submit` on the form.** Enter stops working.
- **Not converting strings to numbers.** `"70" + 170` is not `240`.
- **Reading values outside the submit handler.** They change as the user types.
- **Forgetting `.value`.** You get the input element, not its value.
- **Assuming a radio is checked.** If none is, `.value` on `null` throws.
- **Writing the result with `innerHTML`.** Use `textContent` unless you deliberately want markup.
