This is the part 2 checkpoint. No new concepts — just the whole toolbox, used together.

The goal isn't to copy this exact design. The goal is to see how the pieces fit: tokens first, then layout, then components, then states, then responsive rules.

## The order matters

Don't write CSS from the top of the page to the bottom and hope. Use this order:

1. **Tokens** — colors, spacing, radius, fonts in `:root`.
2. **Reset** — `box-sizing`, margins, images, form fonts.
3. **Page shell** — body, header, main, footer.
4. **Layout** — grid/flex for the big regions.
5. **Components** — panels, fields, buttons, cards, tables.
6. **States** — hover, focus, disabled.
7. **Responsive** — a couple of media queries at the end.

That order means you're never styling a component before you know what space it lives in.

## The pieces worth stealing

Even if you design your own version, these patterns are reusable:

```css
/* 1. Tokens */
:root {
  --brand: #4f46e5;
  --space-4: 16px;
  --radius: 18px;
}

/* 2. Responsive two-column layout */
.layout {
  display: grid;
  gap: var(--space-4);
}

@media (min-width: 760px) {
  .layout {
    grid-template-columns: 1.4fr 0.8fr;
    align-items: start;
  }
}

/* 3. Auto-fitting fields */
.field-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(140px, 1fr));
  gap: 12px;
}

/* 4. A calm focus state */
input:focus-visible {
  border-color: var(--brand);
  box-shadow: 0 0 0 4px var(--brand-soft);
  outline: none;
}
```

<Callout variant="tip" title="Design by subtraction">
If your page feels messy, remove something. One accent color instead of three. One border instead of a border and a shadow. More space between sections. Most design improvements are deletions.
</Callout>

## Before you move on

- [ ] The page works at 320px wide with no sideways scrolling.
- [ ] Body text is readable and contrast is comfortable.
- [ ] Every interactive element has hover and focus-visible states.
- [ ] Spacing uses the scale, not random numbers.
- [ ] The table scrolls inside its wrapper on small screens.
- [ ] No `!important` except the reduced-motion block.
- [ ] You can explain what every line in your `:root` does.
