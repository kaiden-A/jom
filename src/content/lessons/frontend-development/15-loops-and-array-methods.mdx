The food log is a list. To get today's total, you need to visit every item and add up the calories. That's a loop.

JavaScript gives you several ways to do it. They're not competing religions — each one fits a different job.

## The classic for loop

```js
for (let i = 0; i < foods.length; i++) {
  console.log(foods[i].name);
}
```

Three parts: start at `0`, keep going while `i < length`, add `1` each time. It's flexible, but the index bookkeeping is noise when you just want the items.

## for...of

```js
let total = 0;

for (const food of foods) {
  total += food.calories;
}

console.log(total);
```

This reads as "for each food in foods." No index, no off-by-one. Use it when you need to loop and maybe `break` early.

## forEach

```js
let total = 0;

foods.forEach((food) => {
  total += food.calories;
});
```

`forEach` runs a function for each item. It's fine for side effects like logging. It does **not** return a new array, and you can't `break` out of it.

<Callout variant="note" title="forEach vs map">
If you're building a new array, use `map`. If you're doing something for each item (logging, saving, updating a total), `forEach` or `for...of` is fine. `map` returns; `forEach` doesn't.
</Callout>

## map, filter, find

You met these last lesson. Quick recap:

```js
const names = foods.map((food) => food.name);
const highProtein = foods.filter((food) => food.protein >= 20);
const chicken = foods.find((food) => food.name === "Chicken and rice");
```

They're the cleanest way to transform and select.

## reduce: the total machine

`reduce` turns an array into a single value: a total, an average, an object, anything.

```js
const totalCalories = foods.reduce((sum, food) => {
  return sum + food.calories;
}, 0);
```

Read it as:

- `sum` is the **accumulator** — the running total.
- `food` is the current item.
- `0` is the starting value.
- Whatever you return becomes the next `sum`.

For a total, always pass the `0`. Without it, `reduce` starts with the first item and can behave strangely on an empty array.

```js
const totalProtein = foods.reduce((sum, food) => sum + food.protein, 0);
```

That's the whole pattern. Once it clicks, you'll see it everywhere.

## The mistakes everyone makes

- **`for...in` on an array.** It loops over keys as strings. Use `for...of` or a classic `for`.
- **Off-by-one.** `i <= foods.length` reads one item past the end. Use `<`.
- **Forgetting the initial value in `reduce`.** Always pass `0` for sums.
- **Returning nothing from a `map` callback.** You'll get an array of `undefined`.
- **Mutating the original array.** `filter` and `map` return new arrays; use them.
- **Using `forEach` when you need a return value.** It always returns `undefined`.
- **Nested loops for a simple lookup.** Use `find`.
