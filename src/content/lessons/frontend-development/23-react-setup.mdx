Time to leave the single HTML file behind. React projects use a build tool so JSX, imports, and modern JavaScript work in the browser.

We'll use **Vite**. It's fast, it's the standard starting point, and it stays out of your way.

## What you need

- Node.js 20.19 or newer (22 LTS is a safe choice). Check with `node -v`.
- npm, which comes with Node. Check with `npm -v`.
- A terminal. VS Code has one built in (Terminal → New Terminal).

<Callout variant="note" title="Why Node?">
React itself runs in the browser. Node is needed for the development server and the build step — the tools that turn your `.jsx` files into files the browser can run. You're not writing a backend here.
</Callout>

## Create the project

In your terminal, from the folder where you keep projects:

```bash
npm create vite@latest calorie-calculator -- --template react
```

Then:

```bash
cd calorie-calculator
npm install
npm run dev
```

Vite prints a local URL, usually `http://localhost:5173`. Open it. You should see the default Vite + React page.

<Callout variant="tip" title="The two dashes matter">
`npm create vite@latest calorie-calculator -- --template react` — the `--` passes the rest of the flags to the Vite generator. Without it, npm may swallow them. If you forget, Vite will ask you questions interactively. Both work.
</Callout>

## What got created

```
calorie-calculator/
├── index.html
├── package.json
├── vite.config.js
├── public/
└── src/
    ├── main.jsx
    ├── App.jsx
    ├── App.css
    ├── index.css
    └── assets/
```

The files that matter first:

- **`index.html`** — the one HTML page. It has `<div id="root"></div>`.
- **`src/main.jsx`** — finds that root and renders `<App />` into it.
- **`src/App.jsx`** — your main component. Start here.
- **`src/index.css`** — global styles.
- **`vite.config.js`** — Vite settings. You can ignore it for now.

`main.jsx` looks like this:

```jsx
import { StrictMode } from "react";
import { createRoot } from "react-dom/client";
import App from "./App.jsx";
import "./index.css";

createRoot(document.getElementById("root")).render(
  <StrictMode>
    <App />
  </StrictMode>
);
```

<Callout variant="note" title="StrictMode">
`StrictMode` runs some of your code twice in development to help catch bugs. It doesn't run twice in production. If an effect logs twice while you're learning, that's usually why.
</Callout>

## JSX rules

JSX looks like HTML, but it's JavaScript. A few differences:

```jsx
// 1. className, not class
<div className="card">...</div>

// 2. htmlFor, not for
<label htmlFor="age">Age</label>

// 3. Self-closing tags need a slash
<img src="food.jpg" alt="A meal" />
<input type="number" />

// 4. JavaScript goes in braces
<p>{2 + 2}</p>
<p>{name}</p>
<button disabled={isLoading}>Save</button>

// 5. One root element (or a fragment)
return (
  <>
    <h1>Title</h1>
    <p>Text</p>
  </>
);

// 6. Comments
{/* this is a comment */}
```

The `<>...</>` syntax is a **fragment**. It groups elements without adding an extra `<div>` to the page.

## Your first component

Open `src/App.jsx` and replace its contents:

```jsx
function Header() {
  return (
    <header className="site-header">
      <p className="brand">Calorie Calculator</p>
    </header>
  );
}

export default function App() {
  return (
    <div>
      <Header />
      <main className="page">
        <h1>Eat with a plan.</h1>
        <p>Calculate your target, log your food, and see what's left.</p>
      </main>
    </div>
  );
}
```

Save the file. The browser updates automatically. That's hot reload.

<Callout variant="tip" title="Component names start with a capital letter">
`<Header />` is a component. `<header>` is an HTML element. React uses the capitalization to tell them apart. A component named `header` won't work the way you expect.
</Callout>

- [ ] `node -v` shows 20.19 or newer.
- [ ] `npm install` finished without errors.
- [ ] `npm run dev` is running and the page loads.

<Callout variant="warn" title="Stopping the server">
Press `Ctrl + C` in the terminal to stop the dev server. Run `npm run dev` again whenever you come back. You don't need to reinstall every time.
</Callout>

## The mistakes everyone makes

- **Running `npm install` in the wrong folder.** You should see `package.json` in the current directory.
- **Forgetting to start the dev server.** `npm run dev`.
- **Using `class` instead of `className`.** React warns about it.
- **Returning two elements without a fragment.** Wrap them in `<>...</>`.
- **Lowercase component names.** React treats them as HTML tags.
- **Editing files outside `src/` and expecting hot reload.** Vite watches the project, but the React entry is `src/main.jsx`.
- **Importing CSS that doesn't exist.** Check the path.
