Flexbox is great at one dimension. Grid is for two: rows **and** columns at the same time.

If you're building a page layout — a main area with a sidebar, a gallery of cards, a dashboard — Grid is usually the cleaner tool.

## The basics

```css
.layout {
  display: grid;
  grid-template-columns: 1.2fr 0.8fr;
  gap: 24px;
}
```

- `display: grid` makes the element a grid container.
- `grid-template-columns` defines the columns. `1.2fr` and `0.8fr` are fractions of the available space.
- `gap` spaces the rows and columns.

You can also place items explicitly:

```css
.sidebar {
  grid-column: 2;
  grid-row: 1 / 3;
}
```

But most of the time you'll let the grid place things automatically.

## The magic line

This one line gives you a responsive card layout with no media queries:

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 16px;
}
```

Read it as: "Make as many columns as fit, each at least 220px wide, and share the leftover space equally." When the container gets narrower, the number of columns drops. When it gets wider, it adds columns.

<Callout variant="tip" title="minmax + auto-fit = free responsiveness">
This pattern is everywhere: galleries, dashboards, product grids, lesson cards. Learn it once and you'll use it for years.
</Callout>

## Responsive design

Responsive design means the page adapts to the screen instead of assuming a desktop. Three habits:

1. **Start small.** Write the mobile layout first, then add complexity at larger widths.
2. **Use flexible units.** `%`, `fr`, `rem`, `clamp()` — not a fixed `width: 960px`.
3. **Use media queries for real breakpoints**, not device names.

```css
.layout {
  display: grid;
  grid-template-columns: 1fr; /* mobile: one column */
  gap: 16px;
}

@media (min-width: 700px) {
  .layout {
    grid-template-columns: 1.2fr 0.8fr; /* desktop: two columns */
  }
}
```

The `@media (min-width: 700px)` block only applies when the viewport is at least 700px wide. That's mobile-first: the base styles are the small-screen styles.

## Fluid type

Instead of three font sizes for three breakpoints, let the browser interpolate:

```css
h1 {
  font-size: clamp(1.8rem, 5vw, 3rem);
}
```

`clamp(min, preferred, max)` never goes below the minimum or above the maximum. It's a small line that makes headings feel intentional on every screen.

## The mistakes everyone makes

- **Designing only for your laptop.** Resize the browser. Use the DevTools device toolbar.
- **Fixed widths everywhere.** `width: 960px` will break on a phone. Use `max-width` plus `width: 100%`.
- **Horizontal scrolling.** Usually caused by a fixed width, a long unbroken word, or negative margins.
- **Too many breakpoints.** Start with one or two. Add more only when the layout actually breaks.
- **Forgetting `max-width: 100%` on images.** A large image will overflow its container.
- **Using `vw` for everything.** It ignores scrollbars and can make text tiny. Use `clamp()`.
