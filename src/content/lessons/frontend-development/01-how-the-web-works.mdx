Welcome to the start of the whole thing.

By the end of this course you'll have built a **calorie calculator** three times: once with plain HTML and CSS, once with JavaScript, and once with React. Same app, three levels of understanding. The first version won't calculate anything — it'll just look like a real page. That's on purpose.

But before any of that, let's answer the question everyone skips:

## What actually happens when you open a website?

You type an address, hit Enter, and a page appears. Under the hood, it's a short conversation:

1. **The browser asks a server for a file.** Usually that file is called `index.html`.
2. **The server sends the HTML back.** HTML is just text with tags that describe what each piece of content *is*.
3. **The browser reads the HTML** and builds the page structure.
4. **It notices links to CSS and JavaScript** and asks for those too.
5. **CSS makes it look right. JavaScript makes it do things.**

That's the whole loop. Everything else — frameworks, databases, APIs — sits on top of those five steps.

<Callout variant="note" title="The three languages, in one sentence each">
**HTML** is the structure (what's on the page). **CSS** is the style (what it looks like). **JavaScript** is the behavior (what happens when you interact). You need all three, but you learn them one at a time.
</Callout>

<Callout variant="tip" title="What is a tag, really?">
A tag is a label in angle brackets, like `<h1>`. Most tags come in pairs: an opening tag `<h1>` and a closing tag `</h1>`. Whatever sits between them is the content. Some tags, like `<img>`, don't need a closing tag.
</Callout>
