Before Flexbox, centering something vertically in CSS was a personality test. People used floats, tables, absolute positioning, and dark magic. Flexbox made it boring.

Flexbox is for laying out items in **one direction** — a row or a column. That's it. Once you get that, the properties make sense.

## The five properties

You put `display: flex` on the **parent**. The parent becomes a flex container, and its direct children become flex items.

```css
.row {
  display: flex;
  flex-direction: row;      /* row | column */
  justify-content: center;  /* main axis */
  align-items: center;      /* cross axis */
  gap: 16px;
}
```

- **`flex-direction`** — the main axis: `row` (default) or `column`.
- **`justify-content`** — how items are distributed along the main axis.
- **`align-items`** — how items line up on the cross axis.
- **`gap`** — space between items. No margin hacks.
- **`flex-wrap`** — whether items can wrap to the next line.

<Callout variant="note" title="Main axis vs cross axis">
In a row, the main axis is horizontal, so `justify-content` moves things left/right and `align-items` moves them up/down. In a column, the axes swap. This is the one thing people mix up. Say it out loud once: *justify = main, align = cross*.
</Callout>

## Common values

For `justify-content`:

- `flex-start` — pack at the start.
- `center` — center.
- `space-between` — first item at the start, last at the end, equal space between.
- `space-around` / `space-evenly` — variations of even spacing.

For `align-items`:

- `stretch` — fill the cross axis (default).
- `center` — center.
- `flex-start` / `flex-end`.

For items:

- `flex: 1` — grow to fill the available space.
- `flex: 0 0 auto` — don't grow or shrink; keep natural size.
- `flex: 1 1 180px` — start at 180px, then grow or shrink. Great for cards.

<Callout variant="tip" title="Centering, finally">
To center one thing inside a box:

```css
.parent {
  display: flex;
  align-items: center;
  justify-content: center;
}
```

That's the trick everyone used to write blog posts about.
</Callout>

## The mistakes everyone makes

- **Putting `display: flex` on the children.** It goes on the parent.
- **Mixing up `justify-content` and `align-items`.** Main axis vs cross axis.
- **Using margins for spacing.** Use `gap`.
- **Forgetting `flex-wrap`.** Cards shrink into unreadable slivers instead of wrapping.
- **Expecting flex to do a two-dimensional grid.** It can fake it, but Grid is better. Next lesson.
- **A flex item with no width inside a row.** It may collapse or overflow; give it a `flex` value or a `min-width`.
